6. Captura de Leads
6.1 Registro de Lead
Status: ✅ Implementado

Dados Capturados:

interface Lead {
  id: string;
  projectId: string;
  email: string;
  customData: Record<string, any>; // campos extras do formulário
  referralCode: string;     // código único deste lead
  referredBy: string | null; // código de quem indicou
  referralCount: number;    // quantas pessoas indicou
  position: number;
  verified: boolean;
  verificationToken: string;
  createdAt: Date;
  verifiedAt: Date | null;
}
Endpoint: POST /api/public/projects/:slug/join

Request Body:

{
  email: string;
  referredBy?: string;    // código de quem indicou (opcional)
  customData?: object;    // respostas aos campos customizados
}
Response:

{
  id: string;
  position: number;
  referralCode: string;
}
6.2 Geração de Referral Code
Status: ✅ Implementado

6.3 Rastreamento de Indicações
Status: ✅ Básico

Fluxo:

Lead A se cadastra, recebe código ABC123
Lead A compartilha link com ?ref=ABC123
Lead B clica no link e se cadastra
Lead B tem referredBy = ABC123
Lead A tem +1 indicação contabilizada
